# Lumo AI

**A local-first, self-hosted AI assistant project.**

Lumo is a personal AI assistant project that uses locally hosted language models. Optional integrations, including Google Calendar, are being developed to help authorized users manage everyday tasks.

The companion **Lumo Command Center** is planned as a plug-and-play, open-source dashboard for local AI systems. It is not publicly released yet.

## Google Calendar

The planned Google Calendar integration will use OAuth authorization to access an explicitly approved calendar. Authorized users will be able to ask about events and propose new events, with confirmation before creation.

Google account enrollment and live integration activation are separate from this public informational website.
